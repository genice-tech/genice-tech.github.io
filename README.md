**## Core Engineering Tracks**  
   
*** **Odoo 17 / 18 Custom Development:** End-to-end ERP modules, custom ORM models, inventory FEFO workflows, financial journal governance, Role-Based Access Control (RBAC), and pixel-accurate QWeb PDF reports.**  
*** **Python Data Automation & Document Extraction:** High-accuracy parsing of multi-column PDF statements, Excel/CSV data cleaning, statistical validation, and scheduled ETL reporting pipelines.**  
*** **AI Vision OCR & Bot Integration:** Automated data extraction from receipts, bank transfers, and documents using Google Gemini Vision API, integrated with interactive Telegram bots.**  
*** **Enterprise Backend & REST APIs:** Production-ready microservices built with **Python (FastAPI)** and **Java 17/21 (Spring Boot 3/4)** featuring JWT authentication, OpenAPI 3.1 documentation, and Dockerized PostgreSQL deployments.**

**## Featured Case Studies**  
   
**1. **KSER ERP (Odoo 18):** Multi-module humanitarian resource management system with FEFO medical inventory deductions, conditional accounting workflows, offline-first PWA sync, and Gemini Vision OCR wizards.**  
**2. **Recon Ledger API (Java 21 / Spring Boot):** Automated bank reconciliation engine supporting PDF, Excel, and CSV statement extraction with dual-tier fuzzy matching and SHA-256 tamper-proof audit chains.**  
**3. **Nile Dairy & Foods ERP (Odoo 17):** Sales and inventory management module featuring real-time expiration alerts, sequential invoice archiving (`INV-XXXX`), HTTP CSV export controllers, and QWeb PDF reports.**  
**4. **Daftar Al-Tajir API (Python / FastAPI):** Merchant sales, expenses, and debt ledger API equipped with JWT/OTP authentication and automated receipt OCR verification endpoints.**  
**5. **Smart Library Management System (Java 17 / Spring Boot):** Full-stack library platform with 54 REST/MVC endpoints, JWT RBAC security, delivery tracking, and native Right-to-Left (RTL) UI support.**  
**6. **ELMS Catalog API (Async FastAPI / Docker):** High-concurrency catalog and circulation backend utilizing PostgreSQL row-level locking and automated Excel/PDF reporting.**
